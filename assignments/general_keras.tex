\section*{Keras, TensorFlow, and Google Colab}

This assignment uses \texttt{keras3} and \texttt{tensorflow} for R. To work in Google Colab, open the \href{https://colab.research.google.com/github/MansMeg/IntroML/blob/master/additional_material/colab_nb/setup_r_colab.ipynb}{course R setup notebook}, save a copy in Google Drive, and run its setup and training-check cells. Wait for ``PASS: training and prediction work'' before starting the assignment.

Use the assignment report template linked in the notebook to structure your report. Write explanations in text cells and put R code in code cells. Save your notebook and results in Drive, and run the setup cell again at the start of each R session.

For local installation, follow the \href{https://github.com/MansMeg/IntroML/tree/master/additional_material/r_setup}{course R setup guide}. Details on the architecture components are available in the \href{https://keras3.posit.co/}{\texttt{keras3} reference}.
